GOOD TO KNOW

A few things
you might ask.

Everything you need to know before getting started.

What is Zovanion LunaGrid? +

LunaGrid is a Windows desktop spreadsheet application designed for simple, click-first editing, organization, and analysis.

Can I open Excel files? +

Yes. LunaGrid supports importing and exporting .xlsx files, as well as CSV. Not every advanced Excel feature or formula is supported.

Does LunaGrid work offline? +

Yes. LunaGrid is designed as a local desktop app, so routine workbook editing does not require an online account.

What is a .luma file? +

It's LunaGrid's native workbook format for saving and reopening work in the desktop application.

Where can I download the Windows app? +

Download the LunaGrid v1.2 ZIP directly from this site. It contains the Python source and a Windows build script that creates an EXE on your PC; a prebuilt EXE is not included.
